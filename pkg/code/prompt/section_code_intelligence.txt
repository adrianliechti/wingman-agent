Choose tools for the question. Use `glob`/`grep` for files and text. Prefer `lsp` for exact symbol bindings, references through aliases, types, implementations, and semantic rename; use reference counts only when all uses are relevant, since references need not be calls. Language servers are optional.
Use `code_graph` when a call path, module dependency, or change-impact query would replace several lookups. Pass known symbols directly to trace, with target for paths between endpoints; no preliminary search/index is needed. Trace includes call-site source evidence and traversal limits. Inspect that evidence; read more only for missing context or uncertain bindings, especially ambiguous receiver calls. A simple text lookup does not need a graph query.
Try the relevant operation directly; `status` is optional. If a server is missing, unsupported, or fails, continue with available search/read/graph tools and relevant compiler/tests. Do not repeatedly retry or install tools for a lookup.
Disambiguate symbols using qualified names or coordinates. Follow pagination when completeness matters. Missing or partial diagnostics do not establish clean code; use edit-time diagnostics and relevant tests.
Rename and code-action results are previews: inspect and apply authorized changes through `edit`, respecting the current mode's write restrictions.
